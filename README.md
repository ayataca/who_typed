# Who Typed? 展示の起動とXへの投稿

## 起動
```
node server.mjs
```
Chrome で http://localhost:8787 を開く（全画面表示を推奨）。
ホスト用パネルの「X投稿:」に、現在の投稿モード（模擬／本番）が表示されます。

## 体験の流れ
0. スタート（どれかのキーを押す）→ ① 絵を選ぶ → ② 文節を4択で選んで1文を作る（制限時間なし。どれを選んでも意味が通り、選んだ文がそのまま打たれる）→ ③ 薄字の候補を見ながら選ぶ → ④ 文の続きがまとめて補完され、語尾が少し変わる→ ⑤ 内容が大きく食い違う → ⑥ 感想が暴走して打たれる（Deleteでも止まらない）→ 投稿の確認 → 公開 → 問いかけ（「この投稿を書いたのは、誰…？」）→ 終了
- キー: 選択肢は4択で D・F・J・K（左中指・左人差し指・右人差し指・右中指）。⑥の暴走では Delete を押しても止まりません。①のクイズは D・F・J・K の4択（A・S・L・; は白いキーのまま、押しても反応しません）
- 投稿されるのは⑥の暴走で打たれた文だけです（②〜⑤の文は投稿しません）。暴走の文は約1000字で、Xでは最大10件のスレッドになります
- 文章や選択肢は `who-typed-exhibition-scenario.html` の `TEXT` にあります
- リハーサル: ホスト用パネルの「自動操作（リハーサル）」で、キーボードが自分で選びます。`?scene=4` のようにURLに付けると、公開せずそのシーンから始まります

## 待ち時間用：感想タイムライン
- 縦向きのディスプレイで `http://localhost:8787/timeline` を開くと、投稿された感想が新しい順に流れます（5秒ごとに更新）。画面のQRコードをスマホで読み取ると、同じ一覧を見られます
- QRの行き先は、このPCのLAN上のアドレス（ポート8788）です。展示のWi-Fiにスマホをつないでもらってください。アドレスを固定したい場合は `.env` に `PUBLIC_URL=http://…:8788` を書きます（ポートは `VIEW_PORT`）
- 8788番ポートは感想の一覧だけを返します。投稿・削除のAPIや手元写真は、LANには出ません
- 一覧には、`posts/log.jsonl` に成功として残った投稿のテキストだけが出ます（削除したものは消えます）

## 投稿の内容
- 本文：`【来場者の声】★☆☆☆☆ #who_typed` と、展示アンケート2の感想。長い感想は1ツイート125字ごとに区切り、2つ目以降をスレッド（返信）として続けます
- 画像：感想入力の直後に、Webカメラで撮影した手元写真1枚（スレッドの最初のツイートに付きます）

## 安全のための動き
- Xの鍵は `.env` にだけ置き、ブラウザには送りません。サーバーはこのPC（127.0.0.1）からしか接続できません
- 同じ体験（セッション）の投稿は1回だけです。再送されても、最初の結果を返します
- 手元写真がない回は投稿しません
- 「このセッションの公開を中止」を押すと、それ以降は投稿しません。送信中に押した場合は待機を打ち切りますが、Xへの投稿がすでに完了している可能性があるため、ホスト用パネルで結果を確認してください
- 投稿の結果（成功時はURL、失敗時は理由）は、ホスト用パネルに表示されます
- 「直前の投稿をXから削除」で、直前に投稿したもの（スレッド全体）を削除できます

## 記録
`posts/` フォルダに、投稿した手元写真（セッションID.jpg）と記録（log.jsonl）が保存されます。
削除依頼への対応や保存期間の管理に使い、展示終了後は方針に沿って削除してください。
